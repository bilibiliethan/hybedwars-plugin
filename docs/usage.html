简介

HyBedWars 是一个对标 Hypixel 起床战争的完整玩法插件：每队守护一张床，床在则死亡可复活， 床毁则死亡即出局；用资源买装备、升级队伍、拆掉对手的床，最后存活的一队获胜。

插件已内置：完整商店（7 大分类）、队伍升级、陷阱、资源生成器（铁/金/钻石/绿宝石）、 计分板、战绩与星级、独立大厅世界与大厅 NPC、以及“资源自动转经验”的经验模式。

核心设计：地图以「模板世界」形式存放，每局开始时复制出一份干净世界，游戏结束即删除， 所以玩家永远无法永久破坏地图本体。

环境要求

项目要求

编译Maven 3.8+
Folia不支持（folia-supported: false）

安装与编译

1. 编译出 jar

cd HyBedWars
mvn clean package

产物：target/HyBedWars-1.0.0.jar。把它放进服务端的 plugins/ 目录，重启服务器即可。

关于 local-repo/：Paper 1.20.5 官方 paper-api 是快照包，其 POM 引用的 adventure-bom:4.17.0-SNAPSHOT 已下架，直接依赖官方坐标会构建失败。 项目把修正依赖内置在 local-repo/，所以 mvn clean package 开箱即可通过，无需额外配置。

2. 启动后生成的配置

首次启动会在 plugins/HyBedWars/ 下生成：

  • config.yml — 全局设置
  • messages.yml — 全部提示文本（支持 & 颜色码与 %占位符%）
  • shop.yml — 商店价格与上下架
  • arenas.yml — 地图数据（由命令维护）
  • stats.yml — 玩家战绩
  • maps/<地图名>/ — 地图模板世界

快速开始

地图配置完成后，最简单的开局方式：

/bw join experience   # 加入经验模式（4队×8人）的等待房
/bw start <地图名>     # 管理员强制开始一张地图

玩家命令：

  • /bw join [模式] — 随机加入该模式的等待房（不带参数默认 solo）
  • /bw leave — 离开当前对局
  • /bw list — 查看所有地图与状态
  • /bw stats [玩家] — 查看战绩
  • /bw top [kills|wins|beds|level|xp] — 排行榜
提示：主命令 /bw 的别名还有 /bedwars、/qcw、/qichuang。

搭建一张地图（完整流程）

以下以创建一张四人四队地图 mymap 为例。

  1. 创建地图 
    /bw arena create mymap quads
    创建名为 mymap 的四人四队地图。
  2. 进入编辑模式 
    /bw arena edit mymap
    插件会生成一个超平坦虚空世界并把创造模式的你传送进去，可自由建造岛屿、中心岛与商店房。
  3. 设置等待点与观战点 
    /bw arena setlobby       # 站在等待区执行
/bw arena setspectator   # 站在观战位执行
  4. 设置商店与升级 NPC 位置 
    /bw arena setshop        # 商店村民位置
/bw arena setupgrades    # 升级村民位置
  5. 逐个设置队伍（红 / 蓝 / 绿 / 黄） 
    /bw arena setspawn red    # 队伍出生点
/bw arena setgen red      # 队伍铁/金生成点
/bw arena setbed red      # 队伍床（站在床上或对着床执行）
    setbed 会自动读取床的朝向，每局开始时按记录位置与朝向重建队伍颜色的床。
  6. 设置公共生成器（建议至少各 1 个） 
    /bw arena adddiamond   # 中心岛钻石生成点
/bw arena addemerald   # 中心岛绿宝石生成点
    可在末尾加数字自定义刷新间隔（秒/个）：/bw arena adddiamond 20。
  7. （可选）限制建造区域 
    /bw arena pos1
/bw arena pos2
  8. 检查配置是否完整 
    /bw arena info
    会列出缺失项；配置完整时提示“可以开始游戏”。
  9. 保存并退出编辑 
    /bw arena done
    地图模板写入 plugins/HyBedWars/maps/mymap/，之后 /bw start mymap 即可开局。
注意：如果地图坐标全部为空，开局会进不去、死亡也会异常。务必先执行 /bw arena info 确认所有队伍出生点 / 床 / 资源点都已设置，再 done。

玩法机制

资源生成器

  • 队伍生成器：每队出生点各刷铁与金，速度随「熔炉」升级提升。
  • 公共生成器：钻石与绿宝石，按游戏时间自动升级速度。
  • 掉落物不会消失，但同一生成点附近同种掉落超过 48 个会暂停刷新，避免卡服。
资源各等级间隔（秒/个）升级时间点
铁锭1.5 → 1.2 → 0.9 → 0.6随熔炉等级
金锭8 → 6 → 4 → 2随熔炉等级
钻石30 → 20 → 156 分钟 / 12 分钟
绿宝石60 → 45 → 3012 分钟 / 24 分钟

床与死亡

  • 每局开始时按记录位置与朝向重建队伍颜色的床。
  • 敌方床周围 5 格内禁止放置方块（防「包床」）。
  • 床被破坏后，该队成员死亡即最终击杀，直接进入旁观。
  • 床还在时死亡 → 5 秒后复活，保留已购买的永久装备（剑/镐/斧/剪刀/护甲/弓）。
  • 掉进虚空（Y < 0）直接死亡。
  • 死斗时间轴：30 分钟所有床自动消失；45 分钟强制结束，存活人数最多的队伍获胜。

商店（右键商店村民）

7 大分类：方块 / 近战武器 / 护甲 / 工具 / 远程武器 / 药水 / 功能道具。

  • 货币为背包里的实际物品：铁锭、金锭、钻石、绿宝石；经验模式则统一用经验值结算。
  • 普通点击买 1 次，潜行点击一次买 5 次（可在 shop.bulk-buy-amount 调整）。
  • 永久装备死亡后保留，且不会买到比当前更低的等级。
特殊道具行为
火球右键发射，炸开玩家放置的方块（不破坏地图与床）
TNT放下即点燃，引信 2 秒
搭桥蛋投掷后自动铺出 3 格宽的队伍颜色羊毛桥
床虱召唤蠹虫并自动锁定最近敌人，30 秒后消失
梦境守卫召唤铁傀儡守家，120 秒后消失

魔法牛奶30 秒内不触发敌方陷阱
海绵放置后吸干半径 5 格内的水
水桶可放置，8 秒后自动清除，防止地图被永久改造
末影珍珠3 秒冷却（可配置）

计分板与战绩

侧边栏实时显示地图、模式、游戏时间、下一事件倒计时、各队存活人数与床状态（✔/✖）、个人击杀与破床数， 并用队伍颜色给玩家名字上色、关闭队内友伤。

战绩存于 plugins/HyBedWars/stats.yml，内存缓存 + 定时异步落盘。 经验：胜利 +100、击杀 +10、最终击杀 +30、破床 +25、每局 +5；每 5000 经验升 1 星（均可配置）。

经验模式怎么玩

经验模式把「捡资源 → 攒货币 → 买装备」压缩成更快的循环：

  1. 捡到即转化——地上的铁/金/钻石/绿宝石不进背包，拾取瞬间按比例变成经验值。
  2. 商店全面改用经验结算——商品价格 = 原资源价 × 该资源的经验价值。
  3. 计分板 / 商店首页实时显示经验余额。
资源单份经验价值商店等价示例
铁锭1羊毛 ×16 = 4 经验
金锭4木板 ×16 = 16 经验、金苹果 = 12 经验
钻石12锋利之剑 = 48 经验、治疗池 = 24 经验
绿宝石30钻石剑 = 120 经验、末影珍珠 = 120 经验

额外奖励：击杀 +10 经验、破坏床 +25 经验（experience.kill-reward / bed-reward，设为 0 可关闭）。

想在普通模式地图也开经验经济？进入编辑模式执行 /bw arena toggleexp， 开关写进 arenas.yml 的 experience-economy 字段，与模式无关、随时可切。

配置项说明

常见问题

Q：地图世界加载失败？

检查 plugins/HyBedWars/maps/<地图名>/ 是否存在（即是否执行过 /bw arena done）， 以及服务端根目录下没有同名残留世界文件夹。

Q：玩家死亡后一直在旁观？

说明该队床已被摧毁，这是最终击杀的正常表现；/bw leave 可离开对局。

Q：想用已有的服务器世界当竞技场？

把 worlds.copy-template 设为 false，然后在编辑模式用 /bw arena setworld 绑定该世界名即可（此模式下插件不会删除或还原你的世界）。

Q：想改中文提示 / 商店价格？

直接编辑 messages.yml / shop.yml，然后 /bw reload。

Q：开局进不去、死亡后回到奇怪的地方？

多半是地图坐标为空。执行 /bw arena info <地图> 查看缺失项， 补齐队伍出生点、床、生成点后再 /bw arena done。
