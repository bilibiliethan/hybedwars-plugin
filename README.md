# HyBedWars — 仿 Hypixel 起床战争插件（Minecraft 1.20.5）

一个用 Java 21 / Paper API 1.20.5 编写的起床战争（BedWars）插件，玩法、经济、商店与升级体系完整对标 Hypixel BedWars。

---

## 一、支持的游戏模式

| 模式         | 命令参数         | 队伍数 | 每队人数 | 总人数 | 说明                          |
| ---------- | ------------ | --- | ---- | --- | --------------------------- |
| 单人八队       | `solo`       | 8   | 1    | 8   | 红/蓝/绿/黄/青/白/粉/灰             |
| 双人八队       | `doubles`    | 8   | 2    | 16  | 同上 8 色                      |
| 四人四队       | `quads`      | 4   | 4    | 16  | 红/蓝/绿/黄                     |
| 四队八人       | `mini`       | 4   | 2    | 8   | 红/蓝/绿/黄（体验/快速局）             |
| **经验四队八人** | `experience` | 4   | 8    | 32  | 红/蓝/绿/黄，**资源自动转经验、商店用经验结算** |

> `/bw join` 不带参数默认进入 `solo`。  
> 经验模式的别名：`xp`、`exp`、`经验`、`经验模式`、`经验四队八人`。

---

## 一·五、经验模式怎么玩

经验模式把「捡资源 → 攒货币 → 买装备」压缩成一条更快的循环：

1. **捡到即转化**——地上的铁锭、金锭、钻石、绿宝石不会进入背包，  
   而是走过去拾取的瞬间按比例变成**经验值**（头顶快捷栏会提示 `+N 经验`）。
2. **商店全面改用经验结算**——所有商品与队伍升级都标着经验价，  
   价格 = 原本的资源价 × 该资源的经验价值。
3. **计分板 / 商店首页实时显示经验余额**，商店首页的「我的资源」会换成经验面板。

默认换算比例（`config.yml → experience.values`）：

| 资源  | 单份经验价值 | 商店等价示例                     |
| --- | ------ | -------------------------- |
| 铁锭  | 1      | 羊毛 ×16 = 4 经验              |
| 金锭  | 4      | 木板 ×16 = 16 经验、金苹果 = 12 经验 |
| 钻石  | 12     | 锋利之剑 = 48 经验、治疗池 = 24 经验   |
| 绿宝石 | 30     | 钻石剑 = 120 经验、末影珍珠 = 120 经验 |

额外奖励（`experience.kill-reward` / `bed-reward`，设为 0 可关闭）：  
**击杀 +10 经验、破坏床 +25 经验**。

> 想让 **普通模式** 的地图也开经验经济？进入编辑模式后执行 `/bw arena toggleexp`，  
> 开关会写进 `arenas.yml` 的 `experience-economy` 字段，与模式无关、随时可切。

## 三、编译

```bash
cd HyBedWars
mvn clean package
```

产物：`target/HyBedWars-1.0.0.jar`，丢进服务端 `plugins/` 目录重启即可。

> **关于 `local-repo/` 目录**  
> Paper 1.20.5 官方发布的 `paper-api` 是快照版本，其 POM 引用了 `net.kyori:adventure-bom:4.17.0-SNAPSHOT`，  
> 而该快照已从所有公共仓库下架，直接依赖官方坐标会导致 `Could not find artifact ... adventure-bom` 构建失败。  
> 因此本项目把官方的 `paper-api` 1.20.5 jar 与其 POM 内置在 `local-repo/` 中，  
> 只把那个失效的 BOM 换成已发布的 `adventure-bom:4.17.0`（**API 字节码与官方完全一致，未做任何改动**）。  
> pom 中已把 `local-repo` 声明为优先仓库，所以 `mvn clean package` **开箱即可通过**，无需任何额外配置。
>
> 如果你更希望走官方仓库，也可以删掉 pom 里的 `local-paper-api` 仓库并把版本改回  
> `1.20.5-R0.1-SNAPSHOT`——但那需要那个快照 BOM 重新上线才可能成功。

本项目已实测编译通过并产出可用的 jar。

## 四、搭建一张地图（完整流程）

插件采用「**模板世界 + 每局还原**」的方案：地图放在 `plugins/HyBedWars/maps/<地图名>/`，  
每局开始时复制成一个干净世界，游戏结束后删除，保证地图永远不会被破坏。

```
1. 进服后执行：/bw arena create mymap quads
   → 创建名为 mymap 的四人四队地图

2. /bw arena edit mymap
   → 插件自动生成一个空世界（超平坦虚空）并把你传送进去
   → 你拥有创造模式，随便建造：8/4 个岛屿、中心岛、出生点、商店房等

3. 设置出生点与观战点
   /bw arena setlobby        ← 站在出生点/等待区执行
   /bw arena setspectator    ← 站在观战位执行

4. 设置商店 NPC 位置
   /bw arena setshop         ← 站在想放商店村民的位置
   /bw arena setupgrades     ← 站在想放升级村民的位置

5. 逐个队伍设置（红/蓝/绿/黄）
   /bw arena setspawn red    ← 站在该队出生点执行
   /bw arena setgen red      ← 站在该队铁/金生成点执行
   /bw arena setbed red      ← 放一张床（任何颜色都行），站在床上或对着床执行

   注意：setbed 会自动读取床的朝向，并把靠近床头的那一格作为基准，
   每局开始时插件会按记录的朝向重新放置队伍颜色的床。

6. 设置公共生成器（可选，建议至少各 1 个）
   /bw arena adddiamond      ← 站在中心岛钻石生成点
   /bw arena addemerald      ← 站在中心岛绿宝石生成点

7. 可选：设置建造区域（限制玩家越界建造）
   /bw arena pos1 / /bw arena pos2

8. /bw arena info            ← 检查配置是否完整（会列出缺失项）
9. /bw arena done            ← 保存模板世界并退出编辑
   → 地图模板被写入 plugins/HyBedWars/maps/mymap/
```

最后 `/bw join quads` 或 `/bw start mymap` 即可开局。

## 六、玩法机制

### 生成器

- **队伍生成器**：每队出生点各刷铁与金，速度由「熔炉」升级决定（默认 1.5s/铁、8s/金 → 最快 0.6s/铁、2s/金）。
- **公共生成器**：钻石与绿宝石，按时间自动升级速度。
  - 钻石：30s → 6min 变 20s → 12min 变 15s
  - 绿宝石：60s → 12min 变 45s → 24min 变 30s
- 掉落物不会消失（`setUnlimitedLifetime`），但同一生成点附近堆积超过 48 个会暂停刷新，避免卡服。

### 床与死亡

- 每局开始时按记录的位置与朝向重建队伍颜色的床。
- 敌方床周围 5 格内禁止放置方块（防「包床」）。
- 床被破坏后，该队成员死亡即**最终击杀**，直接进入旁观。
- 床还在时死亡 → 5 秒后复活，保留已购买的永久装备（剑/镐/斧/剪刀/护甲/弓）。
- 掉进虚空（Y < `game.void-y`）直接死亡。
- 死斗时间轴：30 分钟所有床自动消失；45 分钟强制结束，存活人数最多的队伍获胜。

### 商店（右键商店村民）

7 大分类，完整对标 Hypixel：方块 / 近战武器 / 护甲 / 工具 / 远程武器 / 药水 / 功能道具。

- 货币为背包里的实际物品：铁锭、金锭、钻石、绿宝石；**经验模式则统一用经验值结算**（详见「经验模式怎么玩」）。
- 普通点击买 1 次，**潜行点击一次买 5 次**（可配置）。
- 永久装备（剑/镐/斧/剪刀/护甲/弓）死亡后保留，且不会买到比当前更低的等级。
- 特殊道具均带独立行为：

| 道具    | 行为                       |
| ----- | ------------------------ |
| 火球    | 右键发射，炸开玩家放置的方块（不破坏地图与床）  |
| TNT   | 放下即点燃，引信 2 秒             |
| 搭桥蛋   | 投掷后自动铺出 3 格宽的队伍颜色羊毛桥     |
| 床虱    | 投掷后召唤蠹虫并自动锁定最近敌人，30 秒后消失 |
| 梦境守卫  | 召唤铁傀儡守家，120 秒后消失         |
| 紧凑弹出塔 | 放置后原地升起 4 格高的羊毛塔带梯子      |
| 魔法牛奶  | 30 秒内不触发敌方陷阱             |
| 海绵    | 放置后吸干半径 5 格内的水           |
| 水桶    | 可放置，8 秒后自动清除，防止地图被永久改造   |
| 末影珍珠  | 有 3 秒冷却（可配置）             |

### 队伍升级（钻石升级，右键升级村民）

| 升级   | 等级 | 价格（钻石）    | 效果         |
| ---- | -- | --------- | ---------- |
| 锋利之剑 | 1  | 4         | 全队剑 +锋利 I  |
| 护甲保护 | 4  | 2/4/8/16  | 全队护甲逐级 +保护 |
| 急速挖掘 | 2  | 2/4       | 全队永久急迫     |
| 熔炉   | 4  | 4/8/12/16 | 提升铁/金生成速度  |
| 治疗池  | 1  | 2         | 基地范围内持续回血  |

陷阱（最多同时排队 3 个，敌人进入基地 8 格内触发，每种限购一次）：

| 陷阱   | 价格  | 效果                    |
| ---- | --- | --------------------- |
| 出其不意 | 1 钻 | 入侵者失明 + 减速 8 秒        |
| 反攻   | 2 钻 | 全队获得速度 I + 跳跃 II 15 秒 |
| 警报   | 3 钻 | 暴露所有隐身入侵者 15 秒        |
| 疲劳   | 4 钻 | 入侵者获得挖掘疲劳 10 秒        |

### 计分板

侧边栏实时显示：地图、模式、游戏时间、下一个事件与倒计时、各队存活人数与床状态（✔/✖）、个人击杀与破床数。  
同时用计分板队伍给玩家名字上色，并关闭队内友伤。

### 战绩与等级

存储在 `plugins/HyBedWars/stats.yml`，内存缓存 + 定时异步落盘。  
经验：胜利 +100、击杀 +10、最终击杀 +30、破床 +25、每局 +5；每 5000 经验升 1 星（均可配置）。

## 八、实现要点

- **地图还原**：`worlds.copy-template: true` 时每局从 `maps/<名>/` 复制干净世界，结束卸载并删除，模板永不被污染；设为 `false` 可直接使用服务器已有世界。
- **资源不重复刷屏**：生成器按 tick 累积，掉落物有数量上限与拾取延迟。
- **方块记录**：只允许破坏「玩家放置的方块」与床，地图本体不可破坏；爆炸只会摧毁玩家放置的方块，防爆玻璃与床免疫爆炸。
- **死亡流程**：世界开启 `do-immediate-respawn`，死亡后立刻转旁观，等待结束后回到队伍出生点并补发装备，避免原版死亡界面。
- **立即生效**：购买护甲/剑/工程工具后立刻穿戴，购买锋利/保护后全队装备即时刷新。
- **兼容性**：1.20.5 把附魔与药水效果迁移到了 `Registry` 并重命名字段，插件通过 `Compat` 类统一按命名空间 key 解析（反射兜底），避免版本差异导致的编译/运行问题。

## 九、常见问题

**Q：地图世界加载失败？**  
检查 `plugins/HyBedWars/maps/<地图名>/` 是否存在（即是否执行过 `/bw arena done`），以及服务端根目录下没有同名的残留世界文件夹。

**Q：玩家死亡后一直在旁观？**  
说明该队床已被摧毁，这是最终击杀的正常表现；`/bw leave` 可离开对局。

**Q：想用已有的服务器世界当竞技场？**  
把 `worlds.copy-template` 设为 `false`，然后在编辑模式用 `/bw arena setworld` 绑定该世界名即可（此模式下插件不会删除或还原你的世界）。

**Q：想改中文提示？**  
直接编辑 `messages.yml`，然后 `/bw reload`。
